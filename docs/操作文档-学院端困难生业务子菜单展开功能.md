# 学院端困难生业务子菜单展开功能 - 操作文档

## 一、修改概述

本次修改为学院端侧边栏菜单添加了可展开/折叠的子菜单功能，实现了以下效果：

1. **困难生业务** 和 **三大奖业务** 点击后可展开/折叠子菜单
2. **困难生业务** 默认展开，展示「本专科信息处理」「家庭成员信息处理」等子项
3. 点击子菜单项时页面切换带有丝滑的过渡动画
4. 菜单按钮带有悬停和点击反馈动画

## 三、修改的文件

### 1. `src/layouts/CollegeLayout.tsx`

**修改内容**：
- 新增 `MenuItem` 和 `ExpandableMenuGroup` 类型定义（第15-26行）
- 将原来的平铺菜单数组改为分组对象：`difficultyMenuGroup`（第28-39行）和 `awardMenuGroup`（第41-50行）
- `MenuButton` 组件改为使用 `motion.button`，添加 `whileHover` 和 `whileTap` 动画（第94-108行）
- 新增 `ExpandableMenu` 组件（第110-182行），实现可展开的菜单组
- 主布局中的内容区域添加页面切换动画（第251-262行）

**关键代码解释**：

```typescript
// 新增类型定义，用于定义可展开的菜单组
type ExpandableMenuGroup = {
  title: string;        // 菜单组标题（如"困难生业务"）
  icon: string;         // 菜单组图标（如"困"）
  items: MenuItem[];    // 子菜单项数组
  defaultOpen?: boolean; // 是否默认展开
};

// 困难生业务菜单组配置
const difficultyMenuGroup: ExpandableMenuGroup = {
  title: "困难生业务",
  icon: "困",
  items: [
    { path: "/college/difficulty", label: "业务首页", mark: "首" },
    { path: "/college/difficulty/student", label: "本专科信息处理", mark: "本" },
    { path: "/college/difficulty/family", label: "家庭成员信息处理", mark: "家" },
    { path: "/college/difficulty/students", label: "困难生明细", mark: "明" },
    { path: "/college/records", label: "提交记录", mark: "记" },
  ],
  defaultOpen: true,  // 默认展开
};

// ExpandableMenu 组件中的动画配置
<motion.div
  initial={{ height: 0, opacity: 0 }}      // 初始状态：高度为0，透明度为0
  animate={{ height: "auto", opacity: 1 }} // 展开状态：高度自适应，透明度为1
  exit={{ height: 0, opacity: 0 }}         // 退出状态：高度为0，透明度为0
  transition={{ duration: 0.25, ease: "easeInOut" }} // 动画时长0.25秒，缓动效果
  style={{ overflow: "hidden" }}
>
```

## 四、功能使用

### 1. 展开/折叠菜单

- 点击「困难生业务」或「三大奖业务」标题区域，即可展开或折叠子菜单
- 展开时箭头会旋转90度，子菜单会从左侧滑入
- 折叠时子菜单会向左滑出，高度逐渐变为0

### 2. 切换页面

- 点击子菜单项（如「本专科信息处理」），会跳转到对应页面
- 页面切换时带有淡入淡出和左右滑动的过渡动画

### 3. 自定义菜单配置

如需修改菜单内容，编辑 `src/layouts/CollegeLayout.tsx` 中的 `difficultyMenuGroup` 和 `awardMenuGroup` 对象：

```typescript
const difficultyMenuGroup: ExpandableMenuGroup = {
  title: "困难生业务",    // 修改标题
  icon: "困",            // 修改图标
  items: [
    { path: "/path1", label: "菜单项1", mark: "标" },
    // 添加/删除/修改子菜单项
  ],
  defaultOpen: true,     // 修改是否默认展开
};
```

## 五、动画效果说明

### 菜单按钮动画
- **悬停效果**：背景色变为半透明蓝色（`rgba(64, 97, 135, 0.28)`）
- **点击效果**：按钮轻微缩小（`scale: 0.98`）

### 菜单展开动画
- **箭头旋转**：展开时从0度旋转到90度，折叠时从90度旋转到0度（`rotate: isOpen ? 90 : 0`）
- **子菜单展开**：高度从0变为自适应，透明度从0变为1
- **子菜单项入场**：每个子项依次从左侧滑入，带有0.03秒的延迟（`delay: group.items.indexOf(item) * 0.03`）

### 页面切换动画
- **进入**：从右侧滑入（`x: 20` → `x: 0`），透明度从0变为1
- **退出**：向左侧滑出（`x: 0` → `x: -20`），透明度从1变为0
- **等待模式**：使用 `AnimatePresence mode="wait"`，等待当前页面退出动画完成后再显示新页面

## 七、注意事项

1. **framer-motion 依赖**：确保已安装 `framer-motion` 库，否则会报错
2. **菜单状态**：菜单展开状态使用 `useState` 管理，页面刷新后会恢复默认状态
3. **响应式**：菜单展开功能已适配移动端和桌面端
4. **兼容性**：动画效果在现代浏览器中都能正常显示
